# 分支结构

## 1. 如果...那么...

想象一个自动门：**如果**有人靠近，**那么**开门；**否则**，就关门。

在Python中，这个逻辑用 `if` 和 `else` 来表达。

### 基础语法
```python
if 条件:
    # 条件成立时，执行这里的代码
    做某件事
else:
    # 条件不成立时，执行这里的代码
    做另一件事
```

例子：
```
age = int(input("请输入年龄"))# 输入年龄信息
if age >=10:# 如果年龄大于等于10，那么全票
  print("全票")
else:# 否则免票
  print("免票")
```

**关键细节**：
- `if` 和 `else` 后面都要有冒号 `:`
- `else`要与`if`对齐
- 要执行的代码必须**缩进**（通常按4个空格或1个Tab键）
- 代码中的括号和冒号都是英文输入法状态下键入的，否则会报错

### 2. 如果...否则如果...否则...

```
score = 85

if score >= 90:
    print("成绩优秀！")
elif score >= 80:  # “否则如果”
    print("成绩良好！")  # score=85，所以执行这句
elif score >= 60:
    print("成绩及格。")
else:
    print("需要加油了！")
```

## 3. 条件的写法（比较运算符）

| 运算符 | 含义 | 示例 | 结果 |
| :--- | :--- | :--- | :--- |
| `==` | 等于 | `5 == 5` | `True` |
| `!=` | 不等于 | `5 != 3` | `True` |
| `>` | 大于 | `10 > 5` | `True` |
| `<` | 小于 | `10 < 5` | `False` |
| `>=` | 大于等于 | `10 >= 10` | `True` |
| `<=` | 小于等于 | `10 <= 5` | `False` |

```
# 实际应用
temperature = 28

if temperature > 30:
    print("天气炎热！")
elif temperature > 20:
    print("天气舒适。")  # 28>20，执行这句
else:
    print("天气有点冷。")
```

```
password = input("请输入密码：")  # 单等号：把输入的内容“放进”password盒子里

if password != "123456":  # 感叹号+等号：“如果密码 不等于 '123456'”
    print("密码错误！")
else:                     # 否则（如果密码等于“123456”）
    print("登录成功！")
```

## 5. 常见错误

### ❌ 常见错误

```
# 错误1：忘记冒号
if age > 18  # ❌ 报错！少了冒号
    print("成年")

# 错误2：忘记缩进
if age > 18:
print("成年")  # ❌ 报错！print前面没缩进

# 错误3：用了单个等号 =（赋值）而不是双等号 ==（比较）
if password = "123456":  # ❌ 这是赋值，不是比较
    print("登录成功")
```
