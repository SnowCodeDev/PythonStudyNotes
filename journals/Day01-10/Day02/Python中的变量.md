# Python中的变量

## 变量：给数据起个名字

想象一下，你有个盒子。编程里的 **“变量”** ，就是这个盒子。

*   **变量名** = 你贴在盒子上的**标签**（比如“我的糖果”）。
*   **变量值** = 盒子里装的**东西**（比如“10颗糖”）。

你可以在盒子里放东西（**赋值**），可以看里面是什么（**使用**），也可以把旧东西换成新的（**修改**）。一个盒子一次只能装一样东西。

### 1. 创建你的第一个变量（往盒子里放东西）

在 Python 里，用等号 `=` 来“放东西”。等号右边是东西，左边是你给盒子起的名字。

**语法（照葫芦画瓢就行）：**
```python
盒子名字 = 要放的东西
```

**动手试试：**
```python
# 创建一个叫 message 的盒子，里面放一句问候语
message = "你好，Python！"

# 创建一个叫 age 的盒子，里面放一个数字
age = 20

# 创建一个叫 is_ok 的盒子，里面放一个开关状态（是/否）
is_ok = True
```

### 2. 使用变量（看看盒子里有什么）

创建好了，怎么用呢？直接用它的名字！

```python
# 定义一个叫 name 的盒子，放上我的名字
name = "小明"

# 看看盒子里有什么（打印出来）
print(name)  # 输出：小明
```

### 3. 修改变量（给盒子换点新东西）

变量嘛，当然可以变！再给它赋一个新值就行，旧的就没了。

```python
# 一开始，盒子里是 1
counter = 1
print("一开始：", counter)  # 输出：一开始：1

# 换！现在盒子里是 2
counter = 2
print("现在：", counter)    # 输出：现在：2

# 可以基于旧的值算一个新值放进去
counter = counter + 3       # 把盒子里的 2 拿出来，加上 3，得到 5，再放回去
print("计算后：", counter)  # 输出：计算后：5
```

### 4. 给变量起名的规矩

给盒子贴标签，不能乱贴，有几个小规矩：

**✅ 可以用的：**
*   字母（英文大小写都行，比如 `name`, `Age`, `myVariable`）
*   数字（但不能在第一个位置，比如 `var1` 可以，`1var` 不行）
*   下划线 `_`（比如 `user_name`, `_secret`）

**❌ 不能用的：**
*   数字开头（`2you` ❌）
*   空格或奇怪符号（`my name` ❌， `a-b` ❌）
*   Python 的“关键词”（`if`, `for`, `while` 这些词Python自己要用，你不能抢）

**起名小技巧：**
尽量让名字一看就知道里面是什么，用英文单词或拼音。
*   不好的：`a`, `x1`, `abc`（谁知道是啥？）
*   好的：`user_name`（用户名）, `score`（分数）, `is_open`（开着吗？）

**合法和非法名字的例子：**
```python
# ✅ 这些名字是合法的
my_name = "张三"
age_2024 = 25
PI = 3.14        # 大家都用大写表示“不变的数”
_is_valid = True

# ❌ 这些名字是非法的，用了会报错
2nd_place = "亚军"  # 数字不能开头
my-score = 95      # 不能用短横线
class = "编程课"   # 'class'是Python的关键词，不能用
```

### 5. 变量里能放哪些东西？

你的盒子可以放不同类型的东西，最常见的有：

*   **整数**：不带小数点的数，比如 `100`, `-5`, `0`
*   **浮点数**：带小数点的数，比如 `3.14`, `-0.5`, `2.0`
*   **字符串**：一串文字，用**英文**的单引号 `'` 或双引号 `"` 包起来，比如 `'你好'`, `"Python"`
*   **布尔值**：只有两个值，`True`（真/是） 和 `False`（假/否），用来做判断。

用 `type()` 可以看看盒子里到底是什么类型：
```python
age = 25
print(type(age))  # 输出：<class 'int'> (int就是整数)

price = 9.9
print(type(price))  # 输出：<class 'float'> (float就是浮点数)

name = "小红"
print(type(name))  # 输出：<class 'str'> (str就是字符串)
```

### 6. 几个实用的小操作

**一次给多个盒子装东西：**
```python
# 给 a, b, c 三个盒子都放上数字 10
a = b = c = 10

# 给 x, y, z 三个盒子分别放 1, 2, 3
x, y, z = 1, 2, 3
```

**交换两个盒子的东西（不用找第三个盒子）：**
```python
box_a = "苹果"
box_b = "橘子"

# 神奇的交换！
box_a, box_b = box_b, box_a

print(box_a)  # 输出：橘子
print(box_b)  # 输出：苹果
```

**把盒子扔掉（删除变量）：**
```python
temp = "临时笔记"
del temp  # 把叫 temp 的盒子扔掉

print(temp)  # ❌ 报错：NameError: name 'temp' is not defined(因为盒子已经没了)
```

### 7. 新手常见小坑

**坑1：盒子还没造好就用**
```python
# ❌ 错误：这个叫unknown的盒子还没造呢！
print(unknown)

# ✅ 正确：先造好盒子，再往里面看
my_box = "里面有东西"
print(my_box)
```

**坑2：名字大小写不一样，就是两个盒子**
```python
cat = "小猫"
Cat = "大猫"  # 注意C是大写的！

print(cat)  # 输出：小猫
print(Cat)  # 输出：大猫
# Python 很严格，cat 和 Cat 是两个完全不同的盒子！
```
