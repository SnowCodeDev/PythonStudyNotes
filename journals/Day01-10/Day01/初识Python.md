## Python 简介

Python（英式发音：/ˈpaɪθən/；美式发音：/ˈpaɪθɑːn/）是由荷兰人**吉多·范罗苏姆**（Guido van Rossum）创造的一种编程语言，它目前是世界上最受欢迎、用户群体最广泛的编程语言之一。

Python 的核心设计哲学强调**代码的可读性**和**语法的简洁性**。与 C、C++ 或 Java 等同样极具影响力的语言相比，Python 允许开发者用更少的代码行来表达逻辑意图，这降低了学习和开发的门槛，提升了生产效率。

根据多个权威的编程语言排行榜显示，Python 一直保持着极高的热度和流行度。特别值得一提的是，在全球最大的代码托管平台 GitHub 上，Python 已经连续多年占据最受欢迎编程语言的榜首位置，这充分证明了其在开发者社区中的强大生命力和广泛的应用基础。

### Python 编年史

下面是 Python 语言发展历程中的一些关键节点：

*   **1989年12月**：吉多·范罗苏姆为了打发圣诞节的闲暇时光，决定开发一个新的脚本解释器，作为 ABC 语言的继承者，主要用于替代 Unix shell 和 C 语言来完成系统管理任务。新语言以他喜爱的 BBC 喜剧《*Monty Python’s Flying Circus*》命名为 “Python”。
*   **1991年2月**：Python 解释器的初始版本（0.9.0）在 alt.sources 新闻组上发布。
*   **1994年1月**：Python 1.0 正式发布，这是梦开始的地方。
*   **2000年10月**：Python 2.0 发布。从这个版本开始，Python 的开发过程变得更加透明，社区生态开始逐步形成。
*   **2008年12月**：Python 3.0 发布。这是一个里程碑式的版本，引入了许多现代编程语言的特性，但出于改进语言设计的目的，它**不向下兼容** Python 2.x 系列。
*   **2011年4月**：包管理工具 **pip** 首次发布，Python 拥有了标准、便捷的第三方库管理和分发工具，生态发展进入快车道。
*   **2018年7月**：创始人吉多·范罗苏姆宣布从 Python 社区 “终身仁慈独裁者” 的职位上退休。
*   **2020年1月**：在维护了长达11年之后，Python 2.x 系列正式停止官方支持，Python 3 成为唯一的主流和未来。
*   **今天**：Python 凭借其简洁、易学、库丰富的特点，已成为人工智能、数据科学、网络开发、自动化运维等领域的首选语言之一，拥有极其繁荣和活跃的生态系统。

> **版本号小知识**：软件版本号通常采用 `A.B.C` 格式。
> *   **A（主版本号）**：当软件进行重大重构或做出不向下兼容的更改时递增。
> *   **B（次版本号）**：当增加新功能时递增。
> *   **C（修订号）**：当进行错误修复或小幅度改进时递增。

### Python 的优缺点

#### 主要优点
1.  **简单优雅，易于上手**：语法清晰直观，接近自然语言，对初学者非常友好。
2.  **开发效率高**：“用更少的代码做更多的事”，能够快速实现想法，验证概念。
3.  **生态强大，社区活跃**：作为开源语言，拥有海量的第三方库和框架，几乎任何领域都能找到成熟的工具，遇到问题也容易找到解决方案。
4.  **应用领域广泛**：从网站开发、数据分析、人工智能到自动化脚本、科学计算，适用范围极广。
5.  **“胶水语言”特性**：可以轻松地调用或集成由 C/C++ 等其他语言编写的模块。
6.  **优秀的跨平台性**：作为解释型语言，通常可以在 Windows、macOS、Linux 等主流操作系统上无缝运行。

#### 主要缺点
*   **执行效率相对较低**：这是大多数解释型语言的通病。在计算密集型或对性能有极致要求的场景下（如高频交易、游戏引擎核心），C、C++ 或 Rust 等编译型语言通常是更佳选择。

## 安装 Python 环境

“工欲善其事，必先利其器。” 要开始编写和运行 Python 程序，首先需要在你的计算机上安装 **Python 解释器**。

我们推荐安装官方的 **Python 3** 解释器（通常称为 CPython）。请访问 Python 官方网站的 [下载页面](https://www.python.org/downloads/) ，根据你的操作系统选择合适的安装程序。

### Windows 系统安装指南
1.  运行下载好的安装程序。
2.  在安装向导中，**务必勾选 “Add python.exe to PATH”**。这个选项会将 Python 添加到系统环境变量，方便你在任何位置通过命令行启动它。
3.  建议选择 “Customize installation”（自定义安装）模式。
4.  在可选功能页面，确保勾选 `pip`（Python 包管理工具，用于安装第三方库）。
5.  在高级选项中，勾选 “Add Python to environment variables” 和 “Precompile standard library”。
6.  **建议自定义安装路径**，路径中不要包含中文或空格（例如：`C:\Python310`）。
7.  安装完成后，打开“命令提示符”或 PowerShell，输入以下命令验证安装：
    ```bash
    python --version
    pip --version
    ```
    如果正确显示版本号，即表示安装成功。

### macOS 系统安装指南
1.  运行下载的 `.pkg` 安装包。
2.  按照向导提示完成安装（通常只需点击“继续”即可）。
3.  安装完成后，打开“终端”，输入以下命令验证安装：
    ```bash
    python3 --version
    pip3 --version
    ```
    > **注意**：在 macOS 上，通常需要使用 `python3` 和 `pip3` 命令来明确指定使用 Python 3。

### 安装完成后
如果上述验证命令成功执行并输出版本信息，恭喜你！你的 Python 编程环境已经准备就绪。接下来，你可以选择一个趁手的代码编辑器（如 VS Code、PyCharm 等）开始编写你的第一个 Python 程序了。
