### 打印：HelloWord

注：练习文件编号为01a，学习完毕后可在Practice文件夹练习

我们可以使用“print”函数打印字符串到终端。
字符串的表述方式是："你的文字"或'你的文字'
打印helloWord代码：
code：
```
print("helloWord!")
```
或
```
print('helloWord!')
```

**注意：**
示例中所有的括号、引号都在英文状态下键入的，否则会报错：SyntaxError: invalid character '（' (U+FF08)或SyntaxError: invalid character '“' (U+201C)

### 注释你的代码

注释代码可以让代码的可读性更高，在Python中，我们使用‘#’来注释文本。
Python 中有两种形式的注释：

1. 单行注释：以`#`和空格开头，可以注释掉从`#`开始后面一整行的内容。
2. 多行注释：三个引号（通常用双引号）开头，三个引号结尾，通常用于添加多行说明性内容。

例如：

单行注释：`#这是一个单行注释`
多行注释：
```
"""
这是一个示例注释
作者：SnowCodeDev
"""
```
或
```
'''
这是一个示例注释
作者：SnowCodeDev
'''
```
