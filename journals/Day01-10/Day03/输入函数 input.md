## 输入函数 input()

`input()` 函数的作用就像你**和程序说话**，它会让程序停下来等你输入内容，然后把你说的话存起来。

### 基本用法
```python
# 1. 最简单的：让用户输入，然后打印出来
user_input = input("请输入点东西：")
print("你刚才输入的是：", user_input)

# 运行结果示例：
# 请输入点东西：你好！
# 你刚才输入的是：你好！
```

### 重要特点
1. **input() 得到的东西都是“字符串”**
   无论你输入数字还是文字，`input()` 都会把它变成一串字符。

```python
age = input("你今年几岁？")  # 假设你输入：20
print(type(age))  # 输出：<class 'str'>（是字符串，不是数字！）
print(age + 5)    # ❌ 会报错！不能把字符串和数字直接相加
```

2. **如何输入数字？**
   如果需要输入数字进行计算，要用 `int()` 或 `float()` 转换：

```python
# 输入年龄（整数）
age_str = input("你今年几岁？")  # 得到的是字符串，比如 "20"
age = int(age_str)              # 转换成整数 20

# 或者简写成一行：
age = int(input("你今年几岁？"))  # 输入20，得到整数20

# 现在可以计算了
print("10年后你：", age + 10, "岁")

# 输入小数用 float()
height = float(input("你的身高（米）："))  # 输入1.75
print("你的身高是：", height, "米")
```

### 实用示例：简单问答程序
```python
# 收集用户信息
name = input("请问你叫什么名字？")
age = int(input("你今年多大了？"))
city = input("你住在哪个城市？")

# 汇总信息
print("\n--- 你的信息卡 ---")
print("姓名：", name)
print("年龄：", age)
print("城市：", city)
print("明年你就", age + 1, "岁啦！")
```

### 小贴士
- `input()` 括号里的文字是**提示信息**，会先显示出来
- 用户输入完后要按**回车键**确认
- 输入的**所有内容都会变成字符串**，需要数字时要记得转换
