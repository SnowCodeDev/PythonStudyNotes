## 字符串操作

字符串就是一串文字，比如 `"你好"`、`"Python"`。今天学两个最常用的操作。

### 1. 连接字符串（把文字拼起来）

用加号 `+` 可以把多个字符串**拼接**成一个新的。

```python
# 例子1：简单拼接
greeting = "你好，"
name = "小明"
message = greeting + name + "！"
print(message)  # 输出：你好，小明！

# 例子2：拼接更多
part1 = "我爱"
part2 = "学习"
part3 = "Python"
sentence = part1 + part2 + part3
print(sentence)  # 输出：我爱学习Python
```

**注意**：`+` 只能拼接**字符串和字符串**。
```python
# ❌ 错误：字符串不能直接和数字加
age = 20
print("我今年" + age + "岁")  # 会报错！

# ✅ 正确：先把数字转成字符串
age = 20
print("我今年" + str(age) + "岁")  # 输出：我今年20岁

# ✅ 更简单的方法：用逗号
print("我今年", age, "岁")  # print()里用逗号，它会自动处理
```

### 2. 获取字符串中的单个字（字符）

字符串中的每个字（包括字母、数字、标点、空格）都有一个**位置编号**，叫做**索引**。

**重要规则**：
- 索引从 `0` 开始，不是从 `1` 开始！
- 用方括号 `[ ]` 和索引来获取字符。

```python
text = "Python"

# 获取单个字符
print(text[0])   # 输出：P（第1个字符，索引0）
print(text[1])   # 输出：y（第2个字符，索引1）
print(text[2])   # 输出：t（第3个字符，索引2）
print(text[5])   # 输出：n（最后一个字符）

# ❌ 注意：不能越界！
print(text[6])   # 会报错！因为"Python"只有索引0-5
```

**获取最后一个字符的简单方法**：用负索引
```python
text = "Python"
print(text[-1])  # 输出：n（倒数第1个）
print(text[-2])  # 输出：o（倒数第2个）
print(text[-6])  # 输出：P（倒数第6个，也就是正数第1个）
```

### 综合示例：用户信息处理
```python
# 获取用户输入
full_name = input("请输入你的全名（比如：张小明）：")

# 处理字符串
print("你的名字长度是：", len(full_name), "个字")
print("第一个字是：", full_name[0])
print("最后一个字是：", full_name[-1])

# 拼接欢迎语
welcome_msg = "欢迎你，" + full_name + "！"
print(welcome_msg)
```

### 常用操作速查表
| 操作 | 代码示例 | 结果 |
| :--- | :--- | :--- |
| **拼接** | `"Hello" + "World"` | `"HelloWorld"` |
| **长度** | `len("Python")` | `6` |
| **取字符** | `"Python"[0]` | `"P"` |
| **取字符** | `"Python"[-1]` | `"n"` |
